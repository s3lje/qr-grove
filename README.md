# QR to Tree Model

A web project that turns a QR code into a 3D tree model.

I saw this project somewhere online and decided to recreate it myself as a way to learn how it works. This is **not** the original project, and I don't claim credit for the idea.

I don't currently remember where I first came across it. If I track down the original, I will update this README with a link and proper credit to the original author(s).
